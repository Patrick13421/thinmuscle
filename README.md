# 薄肌指数 Thin Muscle Index（TMI）

三个可部署版本，风格不同，题库同一套「无厘头刻板印象」测验。

## 怎么挑
- **v1-经典分型**：最像 SBTI/SVTI，粉紫渐变，逐题点选，结果页分型卡。
- **v2-社死分享卡**：深色海报风，结果页超大标题，方便截图发群。
- **v3-健身房审判**：黑绿赛博健身房风，文案更毒舌一点。

每个文件夹里直接打开 `index.html` 就能本地预览；上传到 Cloudflare Pages 时选对应文件夹，构建命令留空，输出目录填 `/`。

## 部署到已有仓库
把选定版本里的文件拷进 https://github.com/Patrick13421/thinmuscle 根目录（至少要有 index.html），push 后 Pages 会自动重建。

## 说明
纯静态，无后端、无账号。玩法与文案仅供娱乐，刻板印象是故意的搞笑设定，不是医学建议。
